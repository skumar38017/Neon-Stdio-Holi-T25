2️⃣ Run Alembic upgrade head (If Migrations Already Exist)
If you already have migration files and just need to apply them, run:

alembic upgrade head
✅ This will apply all pending migrations to the database.

3️⃣ If No Migrations Exist, Generate an Initial Migration
If you haven't created migrations yet, generate them with:

alembic revision --autogenerate -m "Initial migration"
✅ This creates a new migration file based on your SQLAlchemy models.

4️⃣ Apply Migrations to Database
After generating the migration, apply it using:

alembic upgrade head
✅ This updates your database schema to match your models.

5️⃣ Verify Migration Status
To check which migrations have been applied, run:

alembic history
✅ This lists all migration revisions.

6️⃣ If You Need to Rollback
If something goes wrong and you need to undo the last migration:

alembic downgrade -1
